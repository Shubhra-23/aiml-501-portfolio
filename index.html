Artifact 01
Machine Learning Algorithm Map
Introduction

Getting the right algorithm is half the job in machine learning. I've put this map together so that I have one page which shows how the ten most common algorithms learn and what type of data each one is suited to.

Description
Description
It's an infographic with 10 algorithms in a grid. The rows split them into supervised and unsupervised. The columns are split by type of data: tabular data, computer vision, natural language and generative AI. Each card explains in plain English what the algorithm does and gives a real world use case. There's a strip at the top which shows how AI, machine learning, deep learning and generative AI fit together. Each card also lists related algorithms, so you can see which ones are close cousins.
Objective
To learn to tell the algorithms apart in terms of how they learn and where they fit, so that I can select one on purpose rather than just go with the one I'm used to.
Process
Started with the Workshop One video and article on AI, ML, DL and GenAI. Then selected ten algorithms to cover both learning styles and all four areas. Wrote each one up in plain English and put the cards in a grid so the differences are obvious. Wherever there was no good fit (e.g. in the case of supervised generative models) left the cell blank and added a note as to why. Also added a note on self supervised learning as GPT and BERT don't really fit in either of the rows.
Tools & Technology Used
Claude (an AI assistant) to design and draft the infographic. I reviewed and edited the content.
Claude (Anthropic) Infographic Design GitHub Pages
Value Proposition of the Artifact

I can take a very crowded field and distil it down into something that someone else can use. I'm very much of the opinion that clear explanation of models is absolutely vital if we're to do responsible AI work.

Unique Value
I've tied each algorithm to a real use, with a clear preference for finance and healthcare (loan approval, fraud detection, medical scans etc) as that's where I'm going. I've also flagged up the points where the clean split between supervised and unsupervised breaks down.
Relevance
In healthcare and finance you need people who can explain why a model was selected, not just people who can run it. It's a useful quick reference for analysts, managers and anyone else coming into the field.
References
  • Cloud Simplified. (2024, April 29). What is generative AI | Unraveling the differences between AI, ML, DL, and GenAI [Video]. YouTube. https://www.youtube.com/watch?v=lp_BTL_yADU
  • Costa, B., & Trojahan, M. (2024, August 28). What are the differences between AI, ML, DL, and Gen AI? e-core. https://www.e-core.com/na-en/articles/differences-between-ai-ml-dl-gen-ai

Artifact 02
Neural Network Components
Introduction

Neural networks get called black boxes a lot. I made this deck to open the box and show what is inside, one part at a time.

Description
Description
A 12 slide deck. It opens with an architecture diagram of the input, hidden and output layers. Then one slide each covers layers, neurons, weights and biases, activation functions, loss functions and optimization algorithms. A flowchart shows how they work together in a training loop, and a summary slide explains why visualizing networks matters.
Objective
To understand what each part of a neural network does and how the parts depend on each other, using the TensorFlow Neural Network Playground to see the effects.
Process
I grouped the six components by the question each one answers: structure, computation and learning. Each slide gives a short definition and one visual. I used the Playground to see how data type, noise, features, and layers and neurons change training time, complexity and performance.
Tools & Technology Used
Claude (an AI assistant) to build the slides. TensorFlow Neural Network Playground for the experiments.
Claude (Anthropic) TensorFlow Playground Slide Design GitHub Pages
Value Proposition of the Artifact

Artifact 01 showed that I can sort out which algorithm fits which problem. This one shows I can explain how a model works inside, which matters for responsible AI work.

Unique Value
Every component sits in a group with a reason, and a training loop slide shows how they connect.
Relevance
In healthcare and finance, people have to explain how a model reached a result. Knowing the parts is the start of that.
References
  • TensorFlow. (n.d.). A Neural Network Playground. https://playground.tensorflow.org/
